验证不通过？改用 JWT 登录 →

在已登录 warframe.market ↗ 的浏览器里，从 Cookie 中复制 JWT 的值粘贴到下方。 账号密码仍需填写，用于验证身份。

展开图文步骤（7 步）
如何获取 JWT：
  1. 在浏览器中打开 warframe.market ↗ 并完成登录
  2. 按 F12 打开开发者工具（DevTools）
  3. 切换到 Application / 应用程序 标签页
  4. 左侧找到 Cookies 一栏，点击下方的 https://warframe.market
  5. 右侧表格中找到 Name / 名称 列为 JWT 的行
  6. 双击该行的 Value / 值 列，全选后 Ctrl+C 复制
  7. 将复制的值完整粘贴到下方输入框中
